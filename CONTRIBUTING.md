# Contributing

Bug reports, ideas and pull requests are welcome.

The code is source-available, not open source: see [LICENSE](LICENSE). You may
build and run it privately only to prepare and test a change you send here.

## How a change lands

Development happens in a private repository; this one receives a copy of each
release. A pull request here is therefore not merged as it is: an accepted
change is carried over by hand, keeps you as its author, and appears here with
the next release. The pull request is then closed with a note naming that
release.

## Contributor License Agreement

Every pull request needs the agreement below. To accept it, add this line to
the pull request description:

> I have read and agree to the Contributor License Agreement in CONTRIBUTING.md.

A pull request without that line is not taken.
